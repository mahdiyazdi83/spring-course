# Phase 3 demonstration fixtures

All material in this directory is generated for testing documentation behavior.
The teacher and Heydari roles are simulated, not quotes or code from real people.
Locators starting with `demo:` identify imaginary recordings; no media is provided.
Do not use these locators, summaries or files as real course sources.

`teacher-snapshot/` is a fixed local example snapshot used only to exercise the
Teacher Code presentation. It is not the teacher's repository. Preserve its demo label.
`gpt-examples.ts` supplies short illustrative snippets, not a runnable Spring project.
