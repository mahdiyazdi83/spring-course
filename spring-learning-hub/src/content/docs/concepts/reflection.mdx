## Reflection چیست؟ [#overview]

<SourceBlock id="reflection-overview" source="gpt">

Reflection امکان بررسی اطلاعات نوع‌ها و اعضای آن‌ها را در زمان اجرا می‌دهد. برای نمونه، با یک شیء از نوع `Class` می‌توان اطلاعات متدهای تعریف‌شده روی همان کلاس را خواند.

</SourceBlock>

## یک مثال کوچک در Java [#java-example]

<SourceBlock id="reflection-java-example" source="gpt">

این نمونهٔ مستقل توسط GPT نوشته شده است:

```java title="InspectMethods.java · GPT Example"
import java.lang.reflect.Method;

class InspectMethods {
    public static void main(String[] args) {
        for (Method method : String.class.getDeclaredMethods()) {
            System.out.println(method.getName());
        }
    }
}
```

`getDeclaredMethods()` اعضای تعریف‌شده روی همان کلاس را برمی‌گرداند؛ با فهرست همهٔ متدهای public به‌ارث‌رسیده یکی نیست.

</SourceBlock>

## مرز مفهوم [#pitfalls]

<SourceBlock id="reflection-pitfalls" source="gpt">

دیدن اطلاعات یک سازنده یا متد، به معنی ساختن وابستگی یا اجرای خودکار آن نیست. Reflection ابزار بررسی ساختار است؛ [Dependency Injection](/concepts/dependency-injection/) دربارهٔ نحوهٔ دریافت همکارهای یک شیء صحبت می‌کند.

</SourceBlock>
