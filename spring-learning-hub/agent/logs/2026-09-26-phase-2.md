# Phase 2 — design and reading experience

Implemented the authorized second phase in `spring-learning-hub`; source folders and
the Phase 1 content schema remain unchanged. No real course material was processed.

- Added centralized light/dark tokens, local variable Vazirmatn with its OFL license,
  Persian reading typography, logical RTL spacing and isolated LTR technical content.
- Kept the native Starlight shell/theme state. Overrides are limited to SiteTitle,
  PageTitle and a temporary SearchShell. Added quiet metadata, a build-time learning
  hub/index lists, note/table components and timestamp/topic-only timeline shells.
- Expanded explicitly generated demonstration pages for long Persian prose, Java
  annotations, fenced code, nested lists and tables. Fictional timeline fixtures are
  separate from actual source inventories. No teacher/Heydari source was invented.
- Added Astro formatting/lint coverage; raised the Node minimum to 24.16 for the Astro
  ESLint plugin. Documented conventions in `DESIGN-SYSTEM.md` and updated agent memory.

## Verification

`npm run format` and `npm run check`: formatting, ESLint, Astro/TypeScript, ten content
tests, seven-document validation and static build. Build emits eight pages including
the native 404. Known MDX directive, custom-404 lookup and missing deployment `site`
warnings remain visible and documented in the README.

Manual checks used the built preview in the Codex browser:

- Light/dark home and representative session/concept pages; loaded local Vazirmatn,
  confirmed LTR code and isolated inline identifiers. Reading width caps at 736px.
- 320×780 and 390×844 mobile, 768×1024 tablet, 1024×900 compact desktop,
  1440×1000 desktop and 1920×1080 large desktop. Checked pages had matching document
  client/scroll widths; wide code/table content scrolled within its own region.
- Native mobile menu and TOC, active sidebar/heading links, theme persistence after
  navigation, keyboard skip link with visible focus, search button/shortcut and Escape.
  Search button activation restores focus to the trigger on close. Native modal
  semantics keep underlying page controls inactive. Table ArrowLeft scrolling and
  focus outline were verified at the narrow mobile width.
- Token contrast across normal surfaces: minimum 6.87:1 dark / 4.78:1 light for normal
  text; focus/background 10.78:1 / 5.11:1. This is a targeted accessibility review, not
  a full screen-reader or cross-browser audit.

The search input is visibly disabled; full Pagefind search is Phase 4. Source filtering,
block provenance, actual recording actions and full document history remain future work.
Phase 3 has not started. No architectural correction required a new ADR.
